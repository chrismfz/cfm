Design notes

  1. One endpoint, no logic in the browser. Every tile comes from vhost-profile, which calls the enforcement resolvers. The page holds no copy of a matcher.
  2. What applies, not what is written. Each tile says why: "← exclude *.example-shop.gr", "← auto (under attack)". A dashed tile is inherited.
  3. Read-only first. Each "Edit" link opens the existing page with ?host= filled in. Inline toggles come later and reuse the same API calls.
  4. Bot stats reuse Web Traffic. The data is traffic-mix?host=, the model is traffic-model.js (same classes, colours and action guardrails).
  5. Scope. Admin only in phase 1. If cPanel viewers get it later, strip v2*/ms/src/scope/sig, remove the policies card, and update endpoint_scope_inventory.md.
  6. Click a host anywhere, land here. Hosts on Web Traffic, WAF engine, Overview and Forensics become links to this page.
