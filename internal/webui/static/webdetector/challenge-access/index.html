Challenge Access

A per-vhost / global allow-list that lets specific requests through the interactive challenge — by country, URL path, user-agent, IP / range, ASN or verified crawler. The surgical companion to the coarse challenge on/off toggle.

Exempts the challenge only. A match downgrades a would-be challenge to allow. It does not bypass the WAF (SQLi/RCE/upload/webshell → 403) or an IP block — those stay armed.
Fails open. An unknown country or ASN never matches, so a geo/enrich hiccup can neither grant nor deny an exemption.
DNAT note. Path / UA / country conditions apply in in-path (OpenResty / Angie) mode; in DNAT mode only IP / ASN / host-level intent takes effect (a flagged IP is redirected before the in-path decision).

A recipe creates a ready-made exemption for a common case — pick one, fill the blanks, review, create. Created entries are tagged recipe:<name> so they group in the list.
