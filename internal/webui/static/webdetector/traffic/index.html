Challenge its IPs

Each IP gets a per-IP challenge, not the vhost: other visitors see nothing. A client on it that had already solved a challenge must solve again (its clearance is revoked for the challenge's length). Anyone there who solves passes (and lifts it for that IP). An IP already challenged for longer is left as it is. With CHALLENGE_UNSOLVED_HOLD = enforce, an IP that keeps loading the challenge without solving stays challenged. Never a ban.
