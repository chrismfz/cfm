Quick start · safe rollout workflows

1) Tune threshold

Start with detector-only mode and increase/decrease threshold keys in small steps while checking false positives.

2) Add leniency

Create [<base>.leniency] scoped by MATCH_COUNTRY / MATCH_ASN for noisy sources before changing global policy.

3) Enable blocking safely

Set BLOCK=dryrun first, validate event volume, then move to timed blocks. Keep BLOCK=permanent for last-resort cases.
